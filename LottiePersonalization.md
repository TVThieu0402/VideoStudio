### Kaltura Media

 

Prerequisites:
 

1. upload a video to kaltura
2. add the following tag to the entry: `individeo`
3. add 2 JS attachments with type `Text`:      1. attachment that includes everything related to the animation - add tag `individeo-animation`   2. attachment that includes individeo configurations - add tag `individeo-config`   3. these attachments are usually generated by Adobe After Effect tool (the tool that is creating templates of animations) and you are not supposed to create them yourselves
 

Embed code:
   

```
const config = {
  targetId: 'player-placeholder',
  provider: {
    partnerId: 727, // pid on qa env
    uiConfId: 25383962, // player with lottie plugin
    env: {
        serviceUrl: 'https://api.nvq2.ovp.kaltura.com/api_v3',
        cdnUrl: 'https://api.nvq2.ovp.kaltura.com',
    }
  },
  plugins: {
    lottie: {},
  },
};

const player = KalturaPlayer.setup(config);
await player.loadMedia({ entryId: '1_xxxxxx' });
```
